# Security policy

SO2 Clipper reads local video files and invokes local media and OCR tools. Please report suspected security issues privately so maintainers can investigate before exploit details are public.

Use GitHub's **Security** tab and select **Report a vulnerability** when private vulnerability reporting is available for this repository. Do not post an unpatched vulnerability, exploit steps, or sensitive sample files in a public issue. If GitHub does not offer private reporting, check the repository page for a current private contact route; this project does not publish a dedicated security email address.

Please include the affected version or commit, operating system, a concise impact description, and safe reproduction steps. Do not attach private recordings, credentials, or personal data. No response-time or remediation-time SLA is promised.

Security updates will be described in release notes when a fix is available. Third-party component and media-tool notices are listed in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).
